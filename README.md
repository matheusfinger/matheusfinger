## Projetos em Destaque

Meus trabalhos acadêmicos e pessoais transitam por engenharia de software, otimização, ciência de dados aplicada e bioinformática.

### Atuais (Abertos para Colaboração)
Tenho focado ativamente na construção de ferramentas para bioinformática. **Pull Requests são muito bem-vindos!**
- **Montagem de Genes:** Ferramenta focada no alinhamento e montagem, utilizando ferramentas de alinhamento (`bbduk`) e montagem (`cap3`).
- **Assistente de Anotação de Genes:** Sistema integrado com BLAST, contendo um editor para seleção de regiões de interesse e um sistema de arquivos para gerenciar e salvar as anotações.

### Concluídos
- **MLOps BRFSS:** Pipeline automatizado (treinamento, avaliação e exportação de modelos) para predição de diabetes, operando sobre dados processados via práticas de DataOps.
- **LRU-K Buffer Manager:** Implementação de um gerenciador de buffer (K=2) para o SGBD experimental seal-db.
- **Bicicletar Viz:** Exploração visual interativa utilizando `D3.js` para analisar dados do sistema de compartilhamento de bicicletas, incluindo gráficos de dispersão e mapas de conexões regionais.
- **Simulação de Cidade Inteligente:** Projeto de sistemas distribuídos simulando um ecossistema com switch, múltiplos sensores e clientes analíticos.
- **Otimização Multidimensional:** Software desenvolvido em equipe com foco em programação não-linear para encontrar mínimos em funções complexas.

- **Podcast:** Entrevista exclusiva com a pesquisadora responsável por ser a primeira a sequenciar o RNA do caju.
